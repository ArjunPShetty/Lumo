# Code of Conduct

## Our Commitment

We, as contributors and maintainers of **LUMO – An AI-Powered Voice Assistant Using Arduino**, are committed to fostering an open, inclusive, respectful, and professional environment for everyone participating in this project.

We pledge to make participation in this community a harassment-free experience for all contributors, regardless of experience level or background.

## Our Standards

Examples of behavior that contribute to a positive environment include:

* Using welcoming and professional language
* Being respectful of differing viewpoints and experiences
* Giving and accepting constructive feedback
* Focusing on what is best for the project and community
* Showing empathy and consideration toward other contributors

Examples of unacceptable behavior include:

* Harassment, discrimination, or hate speech
* Personal attacks, insults, or derogatory comments
* Trolling, intimidation, or disruptive behavior
* Publishing private information without explicit permission
* Any conduct that is inappropriate in a professional or academic setting

## Scope

This Code of Conduct applies within all project spaces, including:

* GitHub repositories (issues, pull requests, discussions)
* Project documentation
* Community communications related to LUMO

It also applies when an individual is representing the project in public spaces.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Unacceptable behavior may result in actions such as:

* A warning
* Temporary or permanent removal from the project
* Restriction of participation in project discussions or contributions

All enforcement decisions will be made at the discretion of the project maintainer.

## Reporting Violations

If you experience or witness unacceptable behavior, please report it to the project maintainer.
Reports will be handled discreetly and confidentially where possible.

## Responsibility

Project maintainers have the right and responsibility to remove, edit, or reject contributions that violate this Code of Conduct.

## Acknowledgement

This Code of Conduct is adapted from widely accepted open-source community standards and is intended to ensure a safe and productive collaboration environment.
