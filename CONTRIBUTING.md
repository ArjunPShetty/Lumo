# Contributing to LUMO

Thank you for your interest in contributing to **LUMO – An AI-Powered Voice Assistant Using Arduino**.
Contributions are welcome and appreciated across software, hardware, documentation, and testing.

This document outlines the contribution guidelines to maintain code quality, safety, and consistency.


## Project Overview

**LUMO** is a smart voice-controlled automation system that integrates:

* Arduino for hardware and relay control
* NodeMCU (ESP8266/ESP32) for Wi-Fi connectivity
* A Python-based backend for speech processing and AI-driven responses
* Voice recognition modules, speaker/buzzer feedback, and expandable storage

The project demonstrates the integration of **AI, IoT, and embedded systems** for real-world device control.


## How to Contribute

### 1. Software Contributions

* Python backend (speech recognition, AI/NLP logic, APIs)
* Arduino sketches (relay control, device logic)
* NodeMCU firmware (Wi-Fi communication, protocol handling)
* Bug fixes, refactoring, and performance improvements

### 2. Hardware & Embedded Contributions

* Circuit and wiring optimizations
* Power efficiency improvements
* Support for additional sensors or actuators
* Safety and reliability enhancements

### 3. Documentation

* README improvements
* Setup and installation guides
* Hardware connection diagrams
* Code comments and explanations

### 4. Testing

* Backend testing (Python)
* Hardware testing and validation
* Compatibility testing with different boards and modules

## Coding Standards

### Python

* Follow PEP 8 coding standards
* Use meaningful variable and function names
* Comment complex or non-obvious logic
* Do not commit credentials or sensitive data

### Arduino / NodeMCU

* Write modular and readable code
* Clearly document pin mappings
* Avoid blocking delays where possible
* Ensure safe relay switching logic

## Safety Notice

LUMO controls **real-world electrical appliances**.

* Follow proper electrical safety practices
* Use insulated wiring and certified components
* Handle high-voltage devices with caution
* Contributors are responsible for their own hardware setups

The project maintainer is not responsible for damage caused by unsafe usage.

## Reporting Issues

When reporting an issue, please include:

* Hardware details (Arduino model, NodeMCU, relay module, etc.)
* Software environment (OS, Python version, libraries)
* Steps to reproduce the issue
* Logs, error messages, or screenshots (if available)

## Feature Requests

Feature requests are welcome. Please include:

* A clear description of the feature
* The problem it solves
* Whether it is hardware-related, software-related, or both
* Whether you intend to implement it
